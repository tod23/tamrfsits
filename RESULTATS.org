#+TITLE: Résultats d'entraînement et d'inférence — TAMRFSits
#+AUTHOR: Dossier de résultats (hors README — voir aussi RESULTATS.org à la racine du dépôt)

Ce document récapitule *tous les entraînements et inférences réellement lancés*
sur ce dépôt : la baseline de référence, la famille de runs "fiche capteur"
(généralisation capteur / année de référence), les 8 ablations, et les runs
drone (super-résolution). Chaque entrée pointe le checkpoint élu, sa perte de
validation à la sélection, et les *overrides* Hydra exacts (reproduisibles).

* Rappel : où tout vit et ce qui est versionné

- ~model/<run>/<ckpt>_best_val_total_loss=<v>.ckpt~ — les poids (exclus du git, ~.gitignore~)
- ~model/<run>/hydra_config/{config,hydra,overrides}.yaml~ — la config exacte du run (**versionnée**)
- ~slurm/*.slurm~ — les jobs de lancement (versionnés)
- L'historique complet (~experiments~, pertes, dates) est dans ~hydra/experiments/~

Pour *reproduire* un run (à l'identique, sur DATA) :

#+begin_src shell
python bin/train.py --config model/<run>/hydra_config \
    --ckpt_prefix <run> --sweep_id $(cat model/<run>/hydra_config/overrides.yaml | grep jobid)
#+end_src

C'est exactement ce que fait ~run_all.sh~ (relance la suite complète ci-dessous).

* Famille "fiche capteur" : généralisation à un 3ᵉ capteur (perspective)

> Architecture cible : généraliser la fusion à *N* capteurs (au lieu du couple
> fixe HR/LR), chaque capteur recevant son propre token d'identité. Voir
> README.org section « Généraliser la fiche capteur » pour la formulation
> complète. Ici : ce qui a réellement été *lancé*.

- *Runs déjà faits dans le cadre pair-fixe* : l'ablation ~wo_sensor_token~ ci-dessus
  (968639 : retirer le token capteur coûte ~+0.009~ en val) constitue la preuve
  *expérimentale* que le token d'identité porte de l'information utile. C'est le
  socle sur lequel repose l'extension à un 3ᵉ capteur.
- *Étape suivante (non lancée / proposée)* : run avec un 3ᵉ token (profil drone
  MicaSense HR) en *addition* au couple S2+L8/L9 — **chantier d'architecture**,
  pas une config (voir README "Et un 3ᵉ capteur ?" pour les 4 points à généraliser).
